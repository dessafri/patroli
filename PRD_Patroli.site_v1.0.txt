1. Ringkasan
Patroli.site adalah aplikasi web keamanan aset berbasis online yang dirancang khusus untuk petugas keamanan dan manajer fasilitas. Aplikasi ini mengintegrasikan teknologi QR code, GPS, dan pemantauan real-time untuk memodernisasi sistem patroli keamanan konvensional menjadi solusi digital yang efisien, transparan, dan anti-manipulasi.

Visi
Menjadi platform manajemen keamanan aset terpercaya di Indonesia yang memberikan visibilitas penuh atas aktivitas patroli secara real-time.

Misi
Menghadirkan solusi digital yang mudah digunakan, andal, dan terjangkau bagi tim keamanan di berbagai industri seperti properti, manufaktur, perkantoran, dan perhotelan.

1.1 Permasalahan yang Diselesaikan
	•	Patroli keamanan konvensional tidak dapat diverifikasi secara akurat
	•	Tidak ada visibilitas real-time bagi manajer fasilitas terhadap aktivitas di lapangan
	•	Manipulasi data absensi petugas yang sulit dikontrol
	•	Lambatnya respons terhadap insiden darurat
	•	Pelaporan insiden yang tidak terstruktur dan sulit dilacak
	•	Komunikasi satu arah yang tidak efisien antara manajer dan petugas lapangan

1.2 Proposisi Nilai
	•	Verifikasi patroli berbasis QR code yang tidak bisa dipalsukan
	•	Dashboard pemantauan real-time dengan peta lokasi
	•	Absensi berbasis GPS dengan radius terbatas anti-manipulasi
	•	Panic button untuk respons darurat instan
	•	Broadcast message untuk komunikasi cepat ke seluruh petugas
	•	Laporan otomatis yang dapat diekspor

4. Fitur & Modul Aplikasi
4.1 Peta Modul
Aplikasi Patroli.site terdiri dari dua sisi: Dashboard Admin (web) dan Aplikasi Petugas (mobile web).

MODUL 1: MANAJEMEN CHECKPOINT & QR CODE

4.1.1 Fitur Utama
	•	Tambah, edit, hapus lokasi checkpoint
	•	Generate QR code unik per checkpoint
	•	Konfigurasi metadata checkpoint (nama, gedung, lantai, zona)
	•	Preview dan cetak QR code dalam format PDF
	•	Kelola grup checkpoint per gedung/area
	•	Riwayat scan per checkpoint

4.1.2 Detail Teknis
	•	QR code berisi token terenkripsi unik + timestamp expired 24 jam (opsional)
	•	Anti-replay: QR tidak dapat dipindai lebih dari X kali dalam Y menit
	•	Dukungan format cetak A4, A5, label stiker

MODUL 2: PEMANTAUAN REAL-TIME

4.2.1 Dashboard Admin
	•	Live feed aktivitas scan semua checkpoint
	•	Peta interaktif (Google Maps) posisi petugas dan checkpoint
	•	Status petugas: aktif patroli, standby, offline
	•	Timeline patroli per shift
	•	Notifikasi browser untuk event penting
	•	Filter berdasarkan gedung, shift, tanggal

4.2.2 Peta & Lokasi
	•	Heatmap area yang sudah dan belum dipatroli
	•	Rute patroli yang direncanakan vs aktual
	•	Foto yang diunggah petugas tampil di peta

MODUL 3: MANAJEMEN JADWAL PATROLI

4.3.1 Fitur
	•	Buat template rute patroli (urutan checkpoint)
	•	Jadwalkan patroli berulang (harian, mingguan)
	•	Assign rute ke petugas atau tim
	•	Konfigurasi waktu target di setiap checkpoint
	•	Alert jika petugas melewati checkpoint tanpa scan
	•	Alert jika scan terlambat dari jadwal

MODUL 4: ABSENSI ONLINE ANTI-MANIPULASI

4.4.1 Fitur Absensi
	•	Clock in / Clock out berbasis GPS
	•	Radius geofence yang dapat dikonfigurasi (default: 100 meter)
	•	Foto selfie wajah saat absen (opsional, face verification)
	•	Timestamp server (bukan waktu perangkat) untuk mencegah manipulasi jam
	•	Riwayat absensi lengkap per petugas
	•	Laporan kehadiran bulanan otomatis

4.4.2 Mekanisme Anti-Manipulasi
	•	GPS diverifikasi server, bukan hanya perangkat
	•	Deteksi VPN/GPS spoofing (opsional)
	•	Tidak dapat absen di luar radius yang ditentukan
	•	Waktu absen menggunakan server time, bukan device time

MODUL 5: MANAJEMEN INSIDEN & LAPORAN

4.5.1 Pelaporan Insiden
	•	Form laporan insiden saat atau setelah scan checkpoint
	•	Upload foto/video dari kamera perangkat
	•	Kategori insiden: maling, kebakaran, kerusakan, mencurigakan, dll.
	•	Tingkat prioritas: rendah, sedang, tinggi, kritis
	•	Lokasi otomatis (GPS + checkpoint yang dipindai)
	•	Status tindak lanjut: dilaporkan, diproses, selesai

4.5.2 Dashboard Insiden Admin
	•	List insiden dengan filter status dan prioritas
	•	Assign insiden ke petugas/tim
	•	Histori tindak lanjut dan komentar
	•	Notifikasi real-time insiden baru

MODUL 6: PANIC BUTTON

4.6.1 Fitur Darurat
	•	Tombol panic button besar dan mudah diakses di halaman utama petugas
	•	Tahan tombol selama 5 detik dengan progres bar animasi untuk mencegah tekan tidak sengaja
	•	Kirim alert + lokasi GPS real-time ke SEMUA admin aktif
	•	Notifikasi push + email + SMS (opsional) ke admin
	•	Log waktu, lokasi, dan identitas petugas yang menekan
	•	Tampil di dashboard admin sebagai peringatan merah prioritas tinggi
	•	Petugas dapat menambah catatan singkat setelah menekan

MODUL 7: BROADCAST MESSAGE

4.7.1 Fitur Pesan Siaran
	•	Admin kirim pesan teks ke semua petugas atau grup tertentu
	•	Petugas terima notifikasi in-app dan push notification
	•	Riwayat pesan tersimpan di inbox petugas
	•	Konfirmasi baca (read receipt)
	•	Template pesan untuk instruksi rutin
	•	Jadwalkan pengiriman pesan

MODUL 8: LAPORAN & ANALITIK

4.8.1 Laporan Tersedia
	•	Laporan aktivitas patroli harian/mingguan/bulanan
	•	Laporan kehadiran petugas
	•	Laporan insiden (summary + detail)
	•	Laporan cakupan checkpoint
	•	Laporan performa petugas

4.8.2 Format Export
	•	PDF (laporan terformat dengan logo perusahaan)
	•	Excel/CSV untuk analisis lebih lanjut
	•	Jadwal laporan otomatis via email

6.2 Keamanan
	•	HTTPS wajib di semua endpoint
	•	Enkripsi data sensitif di database (AES-256)
	•	Token JWT dengan expiry dan refresh token
	•	Rate limiting pada endpoint kritis (login, scan, panic button)

	•	Audit log untuk semua aksi kritis admin

	•	Arsitektur dapat menangani hingga 10.000 petugas aktif bersamaan
	•	Horizontal scaling untuk API server
	•	CDN untuk aset statis dan gambar

7. Arsitektur Sistem & Stack Teknologi

React.js + Progressive Web App (PWA) untuk petugas dan dashboard admin

Node.js (NestJS) atau Laravel PHP - RESTful API + WebSocket server

Database
PostgreSQL (data utama) + Redis (cache & real-time sessions)

Storage
AWS S3 atau Google Cloud Storage untuk foto dan dokumen

Maps
Google Maps Platform (Maps JavaScript API + Geocoding API)

8. Alur Pengguna (User Flow)
8.1 Alur Petugas - Patroli
	•	Buka aplikasi Patroli.site di browser smartphone
	•	Login dengan username dan password
	•	Sistem verifikasi lokasi GPS untuk absensi
	•	Clock in (hanya berhasil jika dalam radius lokasi kerja)
	•	Sistem konfirmasi absensi berhasil
	•	Petugas mulai patroli mengikuti rute yang ditentukan
	•	Di setiap checkpoint: buka kamera, arahkan ke QR code
	•	Sistem validasi QR dan lokasi GPS secara bersamaan
	•	Upload foto checkpoint (jika dikonfigurasi wajib)
	•	Tambah catatan insiden jika diperlukan
	•	Konfirmasi scan berhasil, dashboard admin update real-time
	•	Ulangi langkah 6-10 untuk semua checkpoint
	•	Selesai patroli, clock out

8.2 Alur Admin - Pemantauan
	•	Login ke dashboard web dari komputer/tablet
	•	Lihat ringkasan status patroli di halaman utama
	•	Pantau peta real-time posisi dan aktivitas petugas
	•	Terima notifikasi insiden atau panic button
	•	Buka detail insiden, assign ke petugas/supervisor
	•	Kirim broadcast message jika diperlukan
	•	Review dan approve laporan absensi
	•	Download laporan harian/mingguan

8.3 Alur Panic Button
	•	Petugas menghadapi situasi darurat
	•	Tekan dan tahan tombol merah besar di halaman utama selama 5 detik
	•	Sistem merekam lokasi GPS, waktu, dan identitas petugas
	•	Alert dikirim ke SEMUA admin aktif (push notification + in-app)
	•	Dashboard admin menampilkan peringatan merah prioritas tinggi
	•	Admin menghubungi petugas dan mengambil tindakan
	•	Admin menutup alert setelah situasi teratasi

9. Deskripsi Layar Utama
9.1 Layar Petugas
Halaman Login
	•	Form email/username + password
	•	Tombol login dengan loading state

Halaman Utama Petugas
	•	Status patroli saat ini (aktif/tidak aktif)
	•	Tombol Clock In / Clock Out
	•	Tombol PANIC BUTTON (merah, besar, 1/3 layar)
	•	Notifikasi terbaru dari admin
	•	Checkpoint terakhir yang dipindai

Halaman Scan QR
	•	Kamera langsung terbuka
	•	Frame panduan posisi QR code
	•	Feedback vibrate + suara saat scan berhasil
	•	Form: foto + catatan setelah scan berhasil

9.2 Layar Admin Dashboard
Halaman Overview
	•	KPI cards: total petugas aktif, patroli berjalan, insiden hari ini, checkpoint tercakup
	•	Live activity feed (timeline real-time aktivitas semua petugas)
	•	Peta interaktif dengan marker posisi petugas

Halaman Manajemen Petugas
	•	Tabel petugas dengan status (online/offline/patroli)
	•	Detail petugas: jadwal, riwayat patroli, absensi
	•	Tambah/edit/nonaktifkan akun petugas

Halaman Insiden
	•	List insiden dengan filter (status, prioritas, tanggal, petugas)
	•	Detail insiden: foto, lokasi, keterangan, timeline tindak lanjut
	•	Assign dan update status insiden

13. Glosarium & Referensi
13.1 Glosarium
Istilah
Definisi
Checkpoint
Titik lokasi fisik yang dilengkapi QR code sebagai pos pemeriksaan patroli
QR Code
Quick Response Code, kode dua dimensi yang dipindai kamera untuk mengidentifikasi checkpoint
Geofence
Batas wilayah virtual berbasis GPS yang digunakan untuk validasi lokasi absensi
Panic Button
Tombol darurat digital yang mengirim alert instan ke admin saat petugas dalam bahaya
Broadcast Message
Pesan yang dikirimkan serentak ke semua atau grup petugas oleh admin
PWA
Progressive Web App, aplikasi web yang berfungsi seperti aplikasi native di smartphone
Real-time
Pembaruan data yang terjadi hampir instan (< 5 detik) tanpa perlu refresh halaman
JWT
JSON Web Token, standar otentikasi stateless yang digunakan untuk sesi pengguna
Multi-tenant
Arsitektur di mana satu platform melayani banyak klien/perusahaan secara terpisah
Shift
Periode kerja petugas, umumnya 8 jam (pagi, siang, malam)
