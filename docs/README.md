# Patroli.site Documentation Blueprint

Dokumentasi resmi platform manajemen keamanan aset dan patroli digital **Patroli.site**.

---

## 📚 Daftar Dokumen

1. **[Quick Start & Deployment Guide](./01_QUICK_START_DEPLOYMENT.md)**
   - System requirements, environment variables, panduan instalasi lokal, Docker Compose, Linux Bare Metal (Nginx + SSL), dan Cloud hosting (Vercel).
   
2. **[User Manual Petugas Lapangan (Satpam)](./02_USER_MANUAL_SATPAM.md)**
   - Panduan instalasi PWA di smartphone, login, absensi masuk/pulang berbasis geofence, SOP patroli scan QR (online & offline queue), pelaporan insiden, dan prosedur Panic Button.

3. **[Admin & Facility Manager Guide](./03_ADMIN_GUIDE.md)**
   - Setup titik checkpoint & radius geofence, cetak QR Code stiker fisik (satuan & batch), manajemen jadwal/shift, dashboard live monitoring, penanganan panic button, dan ekspor laporan bulanan (PDF / Excel).

4. **[API Reference Documentation](./04_API_REFERENCE.md)**
   - Spesifikasi REST API v1.0, standar autentikasi JWT, endpoint autentikasi, checkpoint, patrol scan, absensi, pelaporan insiden, panic button, dan endpoint ekspor laporan.
